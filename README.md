## Projects

### ACP (Audio Control Panel)
ACP is a professional audio control and routing platform designed for advanced management of the PC audio environment. It provides users with precise control over input and output levels, microphone processing, application routing, muting, playback routing, and custom signal paths through a purpose-built hardware and software interface engineered for performance, flexibility, and control.

Built for live communication, streaming, content creation, and professional audio workflows, ACP enables users to shape and direct sound with a high level of control. It supports advanced microphone management, real-time signal adjustments, audio playback injection through virtual microphone paths, and configurable routing scenarios that go beyond standard desktop audio controls.

- [acp-firmware](https://github.com/StudigoGroupBV/acp-firmware)

- [acp-desktop](https://github.com/StudigoGroupBV/acp-desktop)
